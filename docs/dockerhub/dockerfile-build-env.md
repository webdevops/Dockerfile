# webdevops/dockerfile-build-env

Build environment for [github.com/webdevops/Dockerfile](https://github.com/webdevops/Dockerfile), based on [`webdevops/base-app`](https://hub.docker.com/r/webdevops/base-app). The CI builds and tests the images in it.

Rebuilt every night for linux/amd64 and linux/arm64.

| `latest` | Ubuntu 22.04 |
